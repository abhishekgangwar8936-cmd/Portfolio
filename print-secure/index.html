About the Codebase

Print-Secure: Campus Digital Print Studio

Built by Abhishek Gangwar to solve the widespread privacy risk students face every day when handing over USB drives or forwarding personal PDFs over WhatsApp to cyber cafe print operators. Built with React 19, Vite, Tailwind CSS, pdf-lib, Web Audio API, and real-time synchronization.
